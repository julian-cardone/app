## Core Technical Philosophy

The goal is to remain lightweight, but scalable. In order to ensure future-proof
AI scalability and integration, we maintian certain truths:

- Everything important is text-based (markdown, json).
- One source of truth per concern.
- Machine friendly (consistent naming, metadata).

By maintaining clear boundaries and clean integration points, we can prepare for
an ai-assisted, multi-sourced, automated workflow.
